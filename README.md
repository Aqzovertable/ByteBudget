# ByteBudget — трекер личных финансов

**Демонстрационный проект EXADY.** Мини-приложение для учёта доходов и расходов.

## Возможности
- Добавление доходов и расходов.
- Категории операций и история.
- Автоматический расчёт баланса.
- Поиск и фильтрация операций.
- Визуальная сводка расходов по категориям.
- Удаление операций и сохранение в LocalStorage.
- Адаптивный интерфейс.

## Запуск
Откройте `index.html` в современном браузере. Дополнительные зависимости не нужны.

## Стек
HTML5 · CSS3 · Vanilla JavaScript

## Важно
Это демонстрационный проект, а не банковский сервис. Данные хранятся локально в браузере и не предназначены для хранения критически важной финансовой информации.
